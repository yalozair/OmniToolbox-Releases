# OmniToolbox (أدوات أومني)

ضغط وفك الأرشيفات (ZIP و7Z وRAR وISO وغيرها، مع كلمات المرور)، تحويل الفيديو والصوت، تنظيف النظام، وأدوات التخزين والصيانة — لويندوز وأندرويد.

## التنزيل

من صفحة [الإصدارات](https://github.com/yalozair/OmniToolbox-Releases/releases/latest):

- **ويندوز:** `OmniToolbox-Setup-<version>.exe`
- **أندرويد:** `OmniToolbox-<version>-arm64-v8a.apk` لمعظم الهواتف الحديثة، و`armeabi-v7a` للهواتف القديمة، و`x86_64` للمحاكيات.

التطبيق يبحث عن التحديثات تلقائياً ويثبّتها من داخله.

---

Archives (ZIP, 7Z, RAR, ISO and more, with passwords), media conversion, system cleaning, storage and maintenance tools for Windows and Android. Download the installer or APK from [Releases](https://github.com/yalozair/OmniToolbox-Releases/releases/latest); the app updates itself.

Bundles [7-Zip](https://www.7-zip.org) (GNU LGPL + unRAR restriction) and [libarchive](https://libarchive.org) (BSD); their licenses are shown in the app under Settings → Licenses.
